대시보드 읽는 법

대시보드 열기

  1. 전체 장비 운영 현황 확인

    전체 장비에는 대시보드에서 조회된 모든 장비가 포함됩니다. 정상, 장애, 경고는 장비의 현재 상태별 건수입니다. 상태 정보가 없는 장비도 전체에 포함되므로 상태별 합계와 전체 수가 다를 수 있습니다.

  2. 지도에서 장비 위치 찾기

    지도의 왼쪽 탭으로 전체 장비 리스트를 펼칩니다. 유역을 선택해 목록을 좁힌 뒤 관측소명을 누르면 지도가 해당 위치로 이동합니다. 지도를 확대하면 마커 위에 관측소명이나 장비명이 표시됩니다.

  3. 최근 수신 자료와 상세 상태 확인

    장비 목록의 최근 수신 일시로 마지막 수신 시점을 확인합니다. 최신 데이터에는 최근 수문 관측값 또는 영상 파일명이 표시됩니다. 상세를 열면 수신 이력과 자료 처리 모듈의 상태를 볼 수 있습니다.

알람 확인 및 조치

알람 관리 열기

  1. 알람 상세 열기

    상단 종 아이콘에서 안 읽은 알람을 선택하거나 알람 관리에서 목록의 행을 누릅니다. 상세에서 장비, 발생원인, 발생일시를 확인합니다. 오류 코드 옆 ?에 마우스를 올리면 설명과 확인 항목이 표시됩니다.

  2. 읽음 상태와 조치 상태 확인

    읽음은 내가 알람을 확인했다는 기록입니다. 상세를 열거나 모두 읽음 처리를 사용하면 내 읽음 상태가 갱신됩니다. 조치완료는 다른 사용자도 볼 수 있는 처리 기록입니다. 아직 처리할 알람을 찾으려면 조치 상태에서 미조치를 선택하고 조회합니다.

  3. 조치완료 처리 및 메모 남기기

    조치 후 상세에서 조치완료를 누르고, 확인 창에서 필요한 경우 조치 메모를 입력한 뒤 다시 조치완료를 누릅니다. 메모는 최대 200자이며, 완료 처리는 되돌릴 수 없습니다. 이후 상세의 조치자, 조치일시, 조치 메모에서 처리 내용을 확인합니다. 메모는 조치한 사용자가 수정할 수 있습니다.
